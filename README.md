## 🌟 About Vector

**Vector Food Equipments** specializes in the turnkey planning, 2D/3D layout designing, and comprehensive equipment supply for industrial kitchens, hotels, restaurants, corporate cafeterias, catering units, and food courts across India.

### Core Capabilities
- **Commercial Kitchen Planning & Design:** Efficient ergonomic zoning (receiving, cold storage, prep, cooking battery, dishwash, and dispatch).
- **Custom SS 304 Fabrication:** Heavy-duty worktables, sinks, exhaust hoods, Bain Maries, shelving, and utility counters.
- **Cooking & Processing Equipment:** Industrial gas and induction ranges, combi ovens, tandoors, tilting pans, and fryers.
- **Refrigeration & Dishwashing:** Reach-in chillers, walk-in cold rooms, undercounter counters, and commercial hood/rack dishwashers.
- **Turnkey Exhaust & Ventilation:** Ecology units, SS baffle filters, inline fans, and ducting systems.
- **Maintenance & Technical Support:** Preventative AMC maintenance, genuine spare parts, and on-site emergency repair.

## 🛠️ Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:akashgunasekar/vector.git
   cd vector
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
